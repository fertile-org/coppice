# Tài liệu

Coppice gom cả một đội coding agent lên cùng một bảng: chia việc thành ticket, để agent làm trên branch riêng, và review từng diff trước khi tính là xong. Bắt đầu từ trang Cài đặt để chạy ticket đầu tiên.

| Hướng dẫn | |
| --- | --- |
| [Cài đặt](/docs/install) | Tải bản Beta cho macOS hoặc Linux và chạy ticket đầu tiên |
| [Bắt đầu](/docs/getting-started) | Năm bước từ lúc cài xong đến lần chạy agent đầu tiên |
| [Khái niệm](/docs/concepts) | Ticket đi từ Backlog đến Done ra sao, và ai làm việc gì |
| [Nhà cung cấp](/docs/providers) | Coppice dùng được những agent CLI nào |
| [Plugin](/docs/plugins) | Thêm skill và công cụ MCP cho agent |
| [Hỏi đáp](/docs/faq) | Bản Beta có gì, sắp tới làm gì, và Coppice không phải là gì |
