# データのバックアップ

<a id="download-a-backup"></a>

## バックアップをダウンロードする

**System**（システム）、続いて **Backup**（バックアップ）を開き、**Download backup**（バックアップをダウンロード）を選びます。ボード、チケット、設定、ファイル、エージェントの worktree をまとめた 1 つのファイルが手に入ります。

パスワード、鍵、保存済みのトークンは含まれません。それでもワークスペースのデータはすべて入っているので、人に渡さないでください。

<a id="import-a-backup"></a>

## バックアップをインポートする

移行先のコンピューターで **System**、続いて **Backup** を開き、**Import backup**（バックアップをインポート）を選びます。

インポートすると、そのコンピューターのデータはすべてバックアップの内容に置き換わります。ボードとワークスペースの設定は引き継がれます。パスワード、鍵、フォルダーのパス、エージェントのコマンド、プラグインと MCP の設定は引き継がれないので、もう一度設定してください。サインアウトされることがあります。

保存済みのトークンはバックアップに入っていないので、あとで 1 つずつ貼り直してください。Coppice は必要なトークンごとに "Paste this token again."（このトークンをもう一度貼り付けてください）と表示します。貼り付けて保存します。

<a id="copy-the-folders-by-hand"></a>

## フォルダーを手でコピーする

Coppice を終了して、データフォルダーをコピーすることもできます。

| | データ | ログ |
| --- | --- | --- |
| macOS | `~/Library/Application Support/Coppice` | `~/Library/Logs/Coppice` |
| Linux | `~/.config/Coppice` | `~/.local/state/Coppice/logs` |

このコピーには `secrets` フォルダーが含まれるので、パスワードと同じように扱ってください。CLI のサインイン情報は含まれません。各 CLI がそれぞれ保存しています。

<a id="replace-keys"></a>

## 鍵を入れ替える

バックアップを共有した場合や、誰かがコピーを持っていると思う場合は、新しい鍵を作ります。

**System**、続いて **Backup** を開き、**Replace keys**（鍵を入れ替える）を選びます。新しい管理者パスワードを入力し、チェックボックスをオンにします。Coppice が新しい鍵とデータベースのパスワードを作ります。保存済みのトークンはそのまま使え、全員がサインアウトされます。
