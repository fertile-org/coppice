# ドキュメント

Coppice はコーディングエージェントのチームを 1 つのボードにまとめます。作業をチケットとして並べ、エージェントにそれぞれのブランチで作らせ、すべての diff をあなたがレビューしてから完了にします。まずはインストールから、最初のチケットを動かしてみましょう。

| ガイド | |
| --- | --- |
| [インストール](/docs/install) | macOS または Linux 版の Beta をダウンロードして、最初のチケットを動かす |
| [はじめに](/docs/getting-started) | インストールから最初のエージェント実行までの 5 ステップ |
| [コンセプト](/docs/concepts) | チケットが Backlog から Done まで進む流れと、誰が何をするか |
| [プロバイダー](/docs/providers) | Coppice が使えるエージェント CLI |
| [プラグイン](/docs/plugins) | エージェントにスキルと MCP ツールを渡す |
| [よくある質問](/docs/faq) | Beta の範囲、今後の予定、Coppice ではないもの |

<a id="advanced"></a>

## 応用

- [設定](/docs/settings)：config.toml のすべての項目
- [キーボードショートカット](/docs/shortcuts)：ボード、チケット、レビューの既定のキー
- [データのバックアップ](/docs/backup)：バックアップ、移行、鍵の入れ替え

コードへの貢献や改造をしたい場合は、GitHub の[リポジトリのドキュメント](https://github.com/fertile-org/coppice/tree/main/docs)を見てください。
