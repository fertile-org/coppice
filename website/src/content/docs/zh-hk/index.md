# 文件

Coppice 把一組程式設計代理放到同一塊看板上：把工作排成工單，讓代理在各自的分支上構建，每個 diff 都要經你審查才算數。從“安裝”開始，跑通你的第一個工單。

| [快速上手](/docs/getting-started) | 從安裝到第一次執行代理，只需五步 |
| [核心概念](/docs/concepts) | 工單如何從 Backlog 走到 Done，以及各自由誰負責 |
