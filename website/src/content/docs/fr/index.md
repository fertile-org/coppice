# Documentation

Coppice réunit une équipe d’agents de code sur un seul tableau : mettez le travail en tickets, laissez les agents construire chacun sur sa branche, et relisez chaque diff avant qu’il compte. Commencez par Installer pour lancer votre premier ticket.

| --- | --- |
| [Installer](/docs/install) | Télécharger la Beta pour macOS ou Linux et lancer votre premier ticket |

| [Concepts](/docs/concepts) | Comment un ticket passe de Backlog à Done, et qui fait quoi |
| [Fournisseurs](/docs/providers) | Les CLI d’agents que Coppice pilote |
| [Plugins](/docs/plugins) | Donner aux agents des skills et des outils MCP |
