# Docs

Coppice puts a team of coding agents on one board. You queue work as tickets, and agents build on their own branches. You approve the plan before coding starts, unless you choose Skip planning. Once you start a ticket, agents can continue automatically through the workflow. You review and accept the final diff. Accept and Merge are separate choices. Start with Install.
