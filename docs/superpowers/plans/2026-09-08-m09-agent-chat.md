# M09 Agent Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver first-class human↔agent chat sessions with durable messages, `chat_turn` / `conversation` runs (ticket XOR chat ownership), read-only cwd/tools, run-live streaming, and server-validated `create_ticket` / `create_knowledge` (pending) / `cutoff` actions — without regressing ticket `human_chat` or M06 inbox approval.

**Architecture:** New `chat_sessions` / `chat_messages` tables; `agent_runs.ticket_id` becomes nullable with `chat_session_id` XOR CHECK and dual active unique indexes. Chat enqueue path is separate from ticket `start_run_for_agent`. Context builder + job worker gain a `conversation` arm (no knowledge retrieval). Cwd via `chat_cwd`; write denial fail-closed per connector matrix. SPA Chat feature reuses opencode-session reduce-event/parts wired like `LiveSession.tsx`.

**Tech Stack:** Rust, Axum, SQLx, PostgreSQL, Tokio, React 19, TypeScript, TanStack Query, Zod, Vitest, Docker Compose, MockProvider fixtures.

**Spec:** [docs/superpowers/specs/2026-09-08-m09-agent-chat-design.md](../specs/2026-09-08-m09-agent-chat-design.md)

**Gate:** Do **not** start Tasks 2+ (code) until **M07 and M08 are accepted**. Task 1 (philosophy doc already amended in design-gate) is docs-only and may already be done. Re-verify gate before coding.

Critical SQL:

```sql
-- after chat_sessions / chat_messages exist:
ALTER TABLE agent_runs ALTER COLUMN ticket_id DROP NOT NULL;
ALTER TABLE agent_runs
  ADD COLUMN chat_session_id UUID REFERENCES chat_sessions(id) ON DELETE CASCADE,
  ADD COLUMN chat_message_id UUID REFERENCES chat_messages(id) ON DELETE SET NULL;

ALTER TABLE agent_runs ADD CONSTRAINT agent_runs_ticket_xor_chat_check CHECK (
  (ticket_id IS NOT NULL AND chat_session_id IS NULL)
  OR (ticket_id IS NULL AND chat_session_id IS NOT NULL)
);

DROP INDEX IF EXISTS agent_runs_active_ticket_agent_idx;
CREATE UNIQUE INDEX agent_runs_active_ticket_agent_idx
  ON agent_runs (ticket_id, agent_id)
  WHERE status IN ('queued', 'running') AND ticket_id IS NOT NULL;

CREATE UNIQUE INDEX agent_runs_active_chat_session_agent_idx
  ON agent_runs (chat_session_id, agent_id)
  WHERE status IN ('queued', 'running') AND chat_session_id IS NOT NULL;
```

Also drop/recreate `agent_runs_context_profile_check` to include `'conversation'`.
