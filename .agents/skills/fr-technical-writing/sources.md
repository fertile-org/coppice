## Concentration

OpenWeb 9, Alsacréations 6, Bortzmeyer 5, iamvdo 3, Pascal Martin 3, Delicious Insights 3, OCTO 1.
Environ 13 textes CSS, mise en page, images HTML ou outillage front ; 4 en JavaScript ; 5 sur le réseau et le DNS ; 3 en PHP ; 3 sur Git et SSH ; quelques textes sur l'accessibilité et la méthode. La diversité des auteurs a baissé (de 16 à 11) en échange de preuves de reconnaissance individuelles. Corpus surtout français et centré sur le Web.

Les affirmations techniques, de sécurité, de compatibilité ou de performance de ces textes ne font pas autorité aujourd'hui (DSA et tailles de clés dans FR37, mcrypt et sel manuel dans FR41, Gulp 3 dans FR44, Firebug dans FR42, etc.).
